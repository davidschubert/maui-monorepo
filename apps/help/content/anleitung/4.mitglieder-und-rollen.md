Rollen verhindern zweierlei: dass alle alles können — und dass niemand etwas
kann. In einer Community gibt es fünf davon.

## Die fünf Rollen

| Rolle | Kurz gesagt |
|---|---|
| **Viewer** | Liest die Community und kommentiert mit |
| **Editor** | Verfasst Inhalte — moderiert aber nicht |
| **Moderator** | Moderiert Meldungen, Kommentare und Beiträge — verfasst aber nicht |
| **Admin** | Editor und Moderator zusammen, plus Design und Team |
| **Owner** | Admin, plus Übergabe und Löschung der Community |

Editor und Moderator sind **Geschwister**, keine Stufen: Wer schreibt, muss nicht
moderieren dürfen, und wer moderiert, muss nicht schreiben dürfen. Erst der
Admin vereint beides.

| Recht | Viewer | Editor | Moderator | Admin | Owner |

| Dashboard öffnen | ✓ | ✓ | ✓ | ✓ | ✓ |
| Beiträge verfassen | | ✓ | | ✓ | ✓ |
| Seiten bearbeiten | | ✓ | | ✓ | ✓ |
| Medien verwalten | | ✓ | | ✓ | ✓ |
| Events verwalten | | ✓ | | ✓ | ✓ |
| Kommentare moderieren | | | ✓ | ✓ | ✓ |
| Meldungen bearbeiten | | | ✓ | ✓ | ✓ |
| Beiträge moderieren | | | ✓ | ✓ | ✓ |
| Kurse verwalten | | | | ✓ | ✓ |
| Aktivitäten verwalten | | | | ✓ | ✓ |
| Design und Branding | | | | ✓ | ✓ |
| Team verwalten | | | | ✓ | ✓ |
| Community übergeben | | | | | ✓ |
| Community löschen | | | | | ✓ |

::note
Jedes Mitglied hat **genau eine** Rolle pro Community. Wer mehrere Communities
betreut, kann in jeder eine andere Rolle haben.
::

## Was keine Rolle darf

Abrechnung, Plan und Zahlungsdaten hängen nicht an der Community-Rolle, sondern
am **Arbeitsbereich** — auch ein Owner verwaltet sie dort, nicht im Dashboard
seiner Community. Siehe [Abrechnung](/anleitung/abrechnung).

Ebenso sind instanzweite Dinge (Systemeinstellungen, Nutzerverwaltung über alle
Communities hinweg, Protokolle) dem Plattform-Betrieb vorbehalten und für
Community-Rollen nicht erreichbar.

## Wie jemand Mitglied wird

Deine Community steht unter `deinname.pukalani.app`. Wer sich dort anmeldet,
wird Mitglied — die Anmeldung läuft per Code an die E-Mail-Adresse, ein
Passwort ist nicht nötig.

Die Rolle **Owner** bekommt automatisch, wer die Community anlegt.

::warning
Der Wechsel weiterer Mitglieder auf Editor, Moderator oder Admin läuft derzeit
noch über uns — schreib uns, wen du in welcher Rolle brauchst. Eine
Selbstbedienungs-Oberfläche dafür kommt.
::

## Was du beim Verteilen beachten solltest

- **Sparsam anfangen.** Es ist leichter, Rechte zu geben als sie wieder
  zurückzunehmen.
- **Moderator statt Admin**, wenn jemand nur aufräumen soll — er kommt dann
  gar nicht erst an Design oder Team.
- **Owner bleibt bei dir.** Übergeben ist absichtlich ein eigener, seltener
  Vorgang.
